両SRは、同じ問いに反対の答えを出したのか

Mohamedの掲載24時間解析は、7比較・412例でSMD −0.09［95% CI −0.33, 0.16］です。点推定は0に近く、区間は疼痛が低い方向から高い方向まで含みます。ここから言えるのは、この入力・このモデルでは、24時間の平均的な群間差の方向を明確に示せなかったことです。「冷却は無効」「室温と同等」「意味のある利益は存在しない」という結論には、臨床的重要性の閾値と、その閾値に対する精度の評価が別に必要です。

Huangの掲載24時間解析は、11研究名・12比較・700例でSMD −0.58［−0.89, −0.27］です。掲載入力では、統合CIが0をまたがず、冷却とラベル付けされた群の疼痛が低い方向です。しかし、−0.58は疼痛が58%減ったという意味でも、0–10点尺度で0.58点改善したという意味でもありません。研究内のSDを単位にした平均差です。統計的に0と区別できることと、患者にとって十分な改善であることは、別の判断です。

フォレストプロットの各部分は、何を表しているか

このアプリが扱うのは、原則として評価時点の疼痛強度の平均値です。疼痛の発生割合、鎮痛薬を飲んだ割合、治療前からの変化量、患者ごとの改善確率とは異なります。Ajeeshには一般疼痛のNRSと打診痛のVASがあり、ここでは一般疼痛を用います。同じ24時間でも、評価対象の違う数値を入れ替えると別のアウトカムの解析になります。

図の要素意味今回の読み方

横線各比較の95%信頼区間。患者の95%がこの範囲に入るという線ではない。効果量推定の不確実性を示す。0をまたいでも、臨床的に重要な利益を否定できるとは限らない。

菱形中心は統合効果、左右端はその95% CI。ランダム効果の菱形は研究効果の平均を推定する。将来の施設・患者集団に生じる効果の範囲を示す予測区間ではない。
I²とτ²I²は観察されたばらつきと標本誤差の関係を要約。τ²はモデル上の研究間分散。I²は「研究の何%が間違い」という値ではない。τ²の単位は効果量の二乗で、MDとSMDでは直接比較できない。

例えばAlharthiの室温対照との原著値では、0–10点尺度の平均差は0.429−0.786＝−0.357点です。一方、SMDは両群の合併SDで割り、小標本補正を加えた値で、約−0.32です。同じ研究の同じ差でも表現する単位が違います。SMDを0–10点に戻す場合には、対象患者に適切な参照SDを選ぶ必要があり、−0.32をそのまま−0.32点と読めません。

0–100と0–10の違いが単なる線形単位変換なら、平均とSDの両方を10で割ってMDにそろえられます。ただしVASとNRSの測定特性、一般疼痛と打診痛、初回処置後と根充後の違いまで、単位変換で解消するわけではありません。尺度上限が原著で確定できない比較をMDから外すのは、同じ単位であるという仮定を隠さないためです。

何が原著で確認でき、何が説明の仮説なのか

患者の出発点は実際に違います。Gundogduは術前痛・打診痛がともに60/100超の患者に限定し、術前平均も冷却91.32、対照94.86と高い集団です。Alharthiは術前疼痛を除外し、Nandakumarの術前平均は約4.7/10です。これらを「同じ患者に同じことをした研究」とみなすことはできません。疼痛の予防と、もともと強い痛みがある患者の治療後疼痛の軽減では、出発点が違います。

ただし、重症度だけで差を説明したとは言えません。Veraも術前VAS 8–10を要求しますが、24時間対照平均は2.02です。Veraは壊死単根歯の根充前、Gundogduは生活大臼歯の根充後であり、歯種、歯髄・根尖の状態、処置段階、器具・送液方法も異なります。これらが差に寄与した可能性はありますが、研究間比較から各因子の寄与や原因を特定することはできません。

測定と救済鎮痛薬にも違いが残ります。Gundogduは「第1日」と記載し、厳密な24時間時刻や服薬と記録の順序が不明です。400mgイブプロフェンを重度痛時に使用します。Veraは600mgを8–12時間ごとに推奨し、Mokhtariは持続痛時に400mgを使用します。Alharthiには、重度痛で鎮痛薬を処方された患者がVAS 10を記す指示があります。観測された疼痛は、このような測定・併用治療の影響も含みます。薬量の違いだけで研究間差が生じたとは断定できません。

Gundogduの第1日平均・SDは原著表でも確認でき、今回のSRの単純な転記誤りではありません。ただし、原著表の記載を確認することと、元データや測定の正確さを検証することは別です。残る差をすべて生物学的な効果差と説明することも、逆に高い値だけから誤記と決めることもできません。

SMDが解消することと、解消しないこと

SMDは群間平均差を研究内SDで割ります。平均とSDを同じ10で割れば分子・分母が同じ割合で変わるため、SMDは変わりません。Gundogduは原著n＝22対21で、どちらの尺度から計算してもHedges gは約−2.01です。SMDは単位の差を取り除きますが、術前重症度の調整や、治療・測定方法の統一を行うものではありません。

0付近の平均でSDが平均を上回る研究は、無痛者と少数の有痛者が混在する分布や床効果と整合します。低い平均だけで全員がほぼ同じ痛みと判断できません。また、SD自体が集団や測定法で変わると、同じ点数差でもSMDは変わります。数値の単位、疼痛水準、分布、群間差を別々に見る必要があります。

チェックを入れる・外す際の扱い

  1. まず全候補の入力と対象を確認する。原著優先・SR補完の同じ規則で一覧を見ます。「全候補」は監査用の集合で、同じPICOの主解析とは限りません。
  2. 次に臨床条件をそろえる。術前有痛／無痛、生活／壊死、根充前／根充後、室温対照など、問いに必要な条件を全研究へ同じように適用します。数値が大きい、あるいは有意性が変わることを採否の基準にしません。
  3. Gundogduを含む・除く結果を感度分析として比較する。入力・モデル・他の研究を固定し、効果量、CI、τ²、人数がどれだけ動くかを記録します。除外してI²が下がることだけで、除外後の結果が正しいとは結論できません。

掲載図を再現できても、その入力が正しいとは限らない

本アプリの「掲載値」は、SRが図に入力した数値を、問題のある箇所も含めて保持します。「原著照合値」は一次試験の記載との対応を確認した数値ですが、原著自体の誤記・報告不足まで解消したという意味ではありません。今回の「原著優先＋SR補完」では、未確定項目を「SR値より」と明示して補い、解析を可能にしています。Ingale・Mokhtariはnのみ、Jain・Ghabraei・Kumariは未確定の数値をSRから暫定採用します。これは統計量の妥当性を確認した操作でも、欠測値を新たに推定した操作でもありません。データの修正と、対象研究の変更を一度に行うと、結果が動いた原因を追跡できなくなるため、次の問題を分けて検討します。

Jain：診断層の集約各群30例の全体人数はあるが、3診断層それぞれのnは不明。掲載値は層の平均・SDの単純平均に一致する。各層10例は仮定。合成SDには層内のばらつきに加え、層平均の違いも必要で、SDの単純平均では代用できない。

Solomonが原著一覧にあるのは、Huangの入力行を追跡したためです。「ここに数値があるから、修正版の主解析へ自動的に追加する」という判断はできません。採用するなら、同じPICO・検索期間・適格基準で他の研究と同様に評価します。このアプリの比較候補は両SRの24時間データを監査するための集合であり、新たな網羅的検索を完了した「全適格試験」の集合ではありません。

多群試験は、研究名が同じかではなく、参加者を共有しているかで扱いが変わります。Vieyraの2つの冷却群は同じ室温対照80人を共有するため、冷却2群を合成するか、依存性を扱う方法が必要です。一方、Mokhtariの濃度別2比較、Nuñoveroの根尖孔拡大あり・なしの2比較は、比較間で対照患者を共有しません。独立な対照を機械的に半分にしてはいけません。人数を重複させないことと、同一試験内の複数比較を統合・モデル化する方針は、分けて決めます。

原著との対応：Alharthi／Mokhtari／Ajeesh／Solomon Table 2／Ghabraei Table 2。その他は各研究詳細と下の照合表に原典を掲載。

統計モデルとサブグループで、解消できること・残ること

固定効果の逆分散重みは概ね1／研究内分散、ランダム効果では1／（研究内分散＋τ²）です。τ²が大きくなると研究間の重みの差が小さくなり、小規模研究の相対的な寄与が増えます。ランダム効果を選んでも、異なる対照や測定対象を同じ問いに変換したことにはなりません。また、I²や異質性検定のP値を見てから都合のよいモデルへ切り替えると、結果に応じて解析方針を変えることになります。主たるモデルは想定する研究効果の違いに基づいて決め、代替設定は感度分析として位置付けます。

24時間の痛みは多くの患者で0付近となり得ます。平均よりSDが大きい値は、無痛者と少数の有痛者が混在するなど、左右対称でない分布と整合します。SMDは平均差をSDで割るため、同じ点数差でもSDが小さい集団ほど絶対値が大きくなります。したがって、SMDの差をすべて冷却の生物学的効果の差として説明できません。床効果だけから平均差解析を一律に無効とはしませんが、小標本、分布の歪み、尺度の混在を含め、近似CIの適切さを検討する必要があります。

サブグループでは、まず根充前／根充後や室温洗浄／追加洗浄なしなど、問いの違いを示す分類を確認すると有用です。歯髄の生活状態、根尖診断、術前痛、介入時間などで分けた結果は、効果修飾の仮説を検討する材料になります。ただし研究単位の比較は無作為化された比較ではなく、例えば術前有痛の研究に特定の洗浄法が集中していれば、どちらの因子による差か分離できません。

「片方の群だけ有意だった」は群間差の証拠ではありません。効果量の差と交互作用に相当する群間検定を確認しますが、少数研究での群間P値は不安定です。多くの因子を試せば偶然の陽性も増えます。不明・混合集団を結果に都合のよい群へ移さず、事前仮説と解析後の探索を区別して記録してください。本アプリではHKSJの現行RevMan群間検定を確定できていないため、その設定では群間検定値を表示しません。

「1研究を外すと有意になった／I²が下がった」だけを理由に、その研究を主解析から外すこともできません。原著誤抽出なら正しい入力へ訂正し、PICO違反なら同じ基準を全研究へ適用します。そのうえで、影響の大きい研究を除いた解析を併記し、結論がどの程度依存するかを示します。

異質性・モデル・探索的サブグループの考え方：Cochrane Handbook 第10章（10.10–10.11）／RevManの統計設定。ここでの各試験への適用は、本アプリのデータに対する方法論的考察です。

GRADEの観点：どの主張について、どこまで確実か

GRADEはSR全体に一つの「品質点」を付ける手続ではありません。対象・比較・アウトカムを定め、その効果についての確実性を評価します。24時間の疼痛強度だけを検討するこのアプリから、疼痛発生率、鎮痛薬使用、長期予後、安全性まで一括して判断できません。ここでは、正式な独立二者によるRoB評価やGRADE判定を完了したとは扱わず、必要な吟味の論点を示します。

GRADEの領域今回確認すべき内容避ける判断
バイアスリスク割付・隠蔽、自己報告疼痛の測定、鎮痛薬の使い方、欠測の理由と群差、報告する時点・尺度の選択。Kumariの割付記載やAlharthiの複数歯も要確認。「RCT」という名称のみで低RoBと決めない。SRの抽出誤りはまず訂正すべき問題で、原著のRoBと混同して形式的に格下げするだけで済ませない。
非一貫性効果の方向と大きさ、CI、τ²、臨床的な違いを調べる。誤抽出の修正後にも差が残るか確認。I²の閾値だけで機械的に格下げしない。I²が低いことを、臨床的に同じ問いである証拠にしない。
非直接性成人永久歯に対する乳歯、初回治療に対する再治療、根充後に対する根充前、室温洗浄に対する追加洗浄なしの対応。あらゆる対象を含めた統合値を、特定の診断・手順へ無条件に適用しない。
不精確さ患者にとって重要な群間差の閾値を設定し、CIがどの効果の範囲を含むか、情報量が十分かを検討。P<0.05なら精確、P≥0.05なら不精確と決めない。SMDの0.2／0.5／0.8を、この疼痛の患者由来MIDと同一視しない。
出版バイアス登録情報、未公表試験、選択的時点報告、取得できない数値表、検索範囲を確認。研究数が少なく検定できないことを、出版バイアスがないことと読み替えない。図の対称性だけで結論を出さない。

確実性の評価枠組み：Cochrane Handbook 第14章。表の研究固有の論点は原著照合情報に基づく評価課題で、最終GRADE判定ではありません。

このアプリでの検討順序

  1. 掲載図を再現する。まず両SRの入力と計算設定を確認します。これは監査の出発点であり、臨床的に採用する解析の決定ではありません。
  2. 同じ研究集合で入力を照合する。群逆転、別対照、温熱群、研究ラベル、nの相違を一つずつ確認します。修正不能な項目は未確定のまま明示します。
  3. 主たるPICOを決める。一括選択は作業を助ける機能です。ボタンが選んだ集合をそのまま「正解」とせず、診断混在・測定起点・対照群・欠測を行ごとに見ます。
  4. 一度に一つの条件を変える。例えば室温対照限定、根充後限定、乳歯・再治療除外、未確認値の仮採用を、それぞれ目的を付けて比較します。nやSDを仮定した解析は主解析と区別します。
  5. 数値と判断を一緒に残す。効果量・CI・研究数・人数・異質性だけでなく、対象PICO、除外理由、採用値の出典、仮定、統計設定を保存します。結果が動かなかったことだけで、偏りがないとは結論しません。
臨床での結論を記すとき：「○○の患者・処置では、室温○○との比較で、○○から24時間後の一般疼痛の群間差は○○［95% CI］と推定された。ただし△△が未解決であり、患者に重要な改善が得られる確実性は□□である」の順に書くと、図の数値と適用範囲を結び付けられます。MDなら尺度と点数差、SMDなら標準化平均差と明記します。□□は、このアプリが自動的に埋める評価ではありません。

統計方法・出典・検証範囲

RevMan方式の連続アウトカム

逆分散法。SMDはHedges gを使用します。N＝nE＋nC、spは両群の合併SDです。値が負であれば、入力された介入群の疼痛が低い方向です。

J = 1 − 3 / (4N − 9) g = J × (meanE − meanC) / sp var(g) = N / (nE × nC) + g² / {2(N − 3.94)} MD = meanE − meanC var(MD) = sdE² / nE + sdC² / nC

0–100を0–10に揃えるMDでは、平均とSDをともに10で割ります。尺度が線形換算できる場合、尺度の違いだけを理由にSMDが必須になるわけではありません。

Mohamed掲載図の再現

MohamedはRのmetaパッケージを使用したと記載しています。Gamma関数によるexact補正・分散、REML、Wald、Q式I²と、同SR Table 3のAlharthiの3桁値を使うと、図の研究別CIと全体の印字が一致します。著者の解析コードを確認した結果ではなく、掲載情報と整合する再現です。

ν = N − 2 J = Γ(ν/2) / {√(ν/2) × Γ((ν−1)/2)} K = 1 − (ν−2) / (ν × J²) g = J × d var(g) = 1/nE + 1/nC + g² × K

τ²、信頼区間、異質性

ランダム効果ではDLまたはREMLを選択できます。統合CIはWaldまたは未修正HKSJ。現行RevMan相当の自動I²は、randomでτ²と典型的研究内分散、fixedでQ式を使います。Mohamed再現はQ式を使用します。

HKSJはqを1以上に切り上げる修正版ではありません。1研究ではHKSJが定義できず、その研究のWald CIを表示します。推定不能・未収束・入力不備を有効な結果に置き換えません。

サブグループと解析単位

各サブグループの統合効果を計算し、Waldでは群間差のχ²検定を表示します。randomでは群ごとにτ²を推定し、その要約の分散を用います。HKSJの現行RevMan群間検定は公開資料で式を確定できないため、群内CIのみを表示します。

生活歯・壊死歯、根尖診断、治療段階などの分類は原著照合に基づきます。SR掲載時の元の分類を再現したサブグループではありません。診断混在や不明例を都合よく一方へ割り振りません。
